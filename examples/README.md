# Fictional examples

The Streamlit public demo reads these local, fictional fixtures:

- `fictional-opportunity.json` — one safe opportunity record.
- `fictional-evidence.json` — evidence cards used in the showcase.
- `fictional-report.json` — structured intelligence, proposal, and audit data.
- `fictional-report.html` — the static full-report presentation.
- `fictional-workflow-output.json` — a compact safe workflow-output example.

They are intentionally self-contained: no value is a real job, customer,
credential, account, live URL, or external service target.

Do not add exported execution data, real job posts, customer information,
generated proposals for real opportunities, or knowledge-base documents without
an explicit privacy and rights review.
