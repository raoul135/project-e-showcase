# Workflows

## Representative

The three workflows under `representative/` are sanitized, production-derived
architecture samples:

- deterministic opportunity scoring;
- hybrid evidence retrieval;
- proposal auditing.

They contain no live workflow IDs, versions, credentials, pinned execution
data, or production service addresses. They are inactive. Any downstream call
node is disabled and uses a configuration placeholder.

## Demo

`demo/fictional-end-to-end-demo.json` is a separate safe demonstration. It uses
only a manual trigger and Code nodes. It requires no credentials and contacts no
external services.

The demo data, evidence, consultant, customer need, score, and proposal are all
fictional.
