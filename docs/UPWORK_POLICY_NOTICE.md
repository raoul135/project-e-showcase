# Upwork policy notice

Project-E is independent and is not affiliated with, endorsed by, or sponsored
by Upwork.

The private operational prototype used browser automation to read an
authenticated job page after receiving a notification. That implementation is
not published here. This showcase includes only a fictional mock contract that
contacts no external service.

At the time this repository was prepared, Upwork's Terms of Use prohibited
robots, spiders, scrapers, and similar mechanisms without written permission.
Upwork's automation guidance also warned that browser tools which read or change
Upwork pages can trigger account restrictions, and directed approved use cases
toward its API process.

Review the current official terms before designing or operating any integration:

- https://www.upwork.com/legal

redistribute data from Upwork or another service.
