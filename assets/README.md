# Project-E visual system

This directory is reserved for sanitized screenshots, diagrams, and demo media.

Before adding an asset, remove account names, email addresses, job/customer
details, workflow IDs, execution IDs, credentials, browser chrome, and local
filesystem paths.

`assets/screenshots/` contains local captures of the fixture-backed dashboard
demo. They are safe promotional source material, not production screenshots.

The visual system uses a navy foundation with cyan/blue for active data flow,
emerald for supported states, amber for review and rose for risk. Rounded cards,
thin connectors and numbered stages are shared across the hero, pipeline,
evidence and fallback diagrams. `assets/diagrams/` contains conceptual visuals
that describe real architecture; they are not fabricated application screens.
